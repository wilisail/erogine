# Erogine

A small learning project for the PayPal AI Hackathon: a curated shop, one AI recommender, and a verified PayPal sandbox checkout.

Built incrementally. Block 1 establishes the account/session foundation; payment integration follows in Block 2. Sandbox only.

Authentication code is adapted from the owner's TemuEvent Feature 2. See THIRD_PARTY_NOTICES.md for reused sources and licenses as they are imported.
